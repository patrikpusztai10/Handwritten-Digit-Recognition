
# 🧠 Handwritten Digit Recognition using Neural Networks

This project demonstrates how to build a neural network to recognize handwritten digits with high accuracy using the MNIST dataset.
---

## 🧰 Requirements

- Python 3.8+
- TensorFlow
- NumPy
- OpenCV (cv2)
- Matplotlib (optional, for visualization)

## 🔁 Main flow

An image with a handwritten digit is added in the Digits folder. The image should be 28x28 pixels for the most accurate results. 
The user should first create the neural network model which will by default be compiled with 50 epochs by calling the method create_model.
Then the images from the Digits folder will be analyzed and the numbers will be predicted.
